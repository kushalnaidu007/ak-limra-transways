# AK Limra Transways

A responsive, static company website. Open `dist/index.html` in a browser, or serve `dist` with any static web server. Upload the contents of `dist` to a static hosting provider.

The site includes transportation, loading and unloading services, cargo details, truck capacities, service states and direct phone links. No build or dependencies are required. Google Fonts are optional; system font fallbacks are provided.

Content, all nine material photographs and fifteen client logos were incorporated from the supplied AK LIMRA Company profile PDF. Vehicle photographs were removed. The original fonts, typography and colour palette are preserved.
